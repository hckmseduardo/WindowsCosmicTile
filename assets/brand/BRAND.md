# CosmicTile brand assets

The same artwork is shared by macOS and Windows. CosmicTile is the product brand; platform names only describe release packages.

- app-icon.png: shared 1024 px artwork, identical in both repositories.
- CosmicTile.icns: macOS app icon.
- CosmicTile.ico: Windows icon with nine embedded resolutions.
- status-template.png and mark-template.svg: monochrome three-tile glyph for template contexts.
- wordmark.png: transparent horizontal logo for light backgrounds.
- brand-board.png: visual identity presentation.

Primary colors: graphite #12171F, cyan #46DCE7, off-white #F3F6FA.
Tagline: Every screen. Your flow.

Preserve the symbol orientation, aspect ratio and clear space. Use the color icon on both platforms and the OS-tinted monochrome mark in the macOS menu bar.
