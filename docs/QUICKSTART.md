# Quick start

1. Extract the ZIP for your CPU: x64 for Intel/AMD, arm64 for Windows on ARM.
2. Launch WindowsCosmicTile.exe. The app starts in the notification area, with all displays floating.
3. Click the tray icon (look in the hidden-icons overflow if needed) and enable individual displays.
4. Use Ctrl + Alt + T to toggle the focused display; add Shift to toggle all displays.
5. Use Ctrl + Alt + R to enter resize mode. Arrow keys adjust width/height. Escape, Enter or the same shortcut exits.
6. Choose Language → English / Français / Português from the tray menu. English is the default.
7. Quit through the tray menu to restore managed windows.

Save/Open dialogs, owned modal windows, tool windows, fixed-size windows and minimized/cloaked windows are excluded. Standard application windows remain tiled. App-specific minimum sizes can still prevent a requested layout.

No administrator permission is required for ordinary apps. Windows privilege restrictions may prevent managing elevated windows. This preview is not Authenticode signed, so SmartScreen can warn. Review the source, release provenance and SHA-256 before deciding whether to run it.
