# CosmicTile v0.2.1

- Add a **Keep awake** tray-menu toggle, with English, French and Portuguese labels.
- Keeps the computer and display awake through a native Win32 power request. Starts disabled each launch; disable or quit to release it.
- Manual locking and screen-saver or organization-enforced locks remain available. No permanent power/security settings are changed.
- Includes GitHub update checks and consent-gated downloads from v0.2.0.

Portable packages are available for Windows x64 and ARM64. Extract the ZIP and run WindowsCosmicTile.exe.
